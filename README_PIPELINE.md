## 1. Pipeline Overview

```
Single front image
        │
        ▼
  HybrIK / SMPLify-X ──► SMPL betas + thetas ──► SMPL mesh (.obj)
        │
        ▼
  Dual-view texture projection  (project_face_body_dual_view.py)
  ├── Front reference image  ──► face / chest / arms / lower body
  └── Back reference image   ──► back chest / back arms / lower body
        │
        ▼
  Iterative kNN gap fill  (white vertex spreading)
        │
        ▼
  Vertex-colored PLY  ──►  UV atlas OBJ + PNG  (for Unity base mesh)
        │
        ▼
  Rebake texture to rigged FBX UV layout  (rebake_texture_to_fbx_uv.py)
        │
        ▼
  FBX-compatible albedo PNG  (import into Unity with bones & animations)
```

## 4. Stage 1 — SMPL Mesh from a Single Image

The SMPL mesh is produced **before** this repository's main scripts run.  
It is generated by fitting SMPL shape parameters (betas, 10-dim) and pose parameters (thetas, 72-dim axis-angle) to a single front-facing image using HybrIK or SMPLify-X.

### What this produces

- **betas** (shape): 10 PCA coefficients controlling body shape (height, weight, proportions)
- **thetas** (pose): 72-dim joint rotations in axis-angle (24 joints × 3)
- These are fed to the SMPL forward model → 6890 vertices, 13776 triangles

### Running the fitting (HybrIK)

```powershell
E:\envs\v23d_local\python.exe C:\V23D\V23D\third_party\HybrIK\scripts\demo_image.py `
    --img-path E:\zero123_dataset\humans_train\person_017\frame_000\reference.png `
    --out-dir E:\V23D_Data\hybrik_output `
    --ckpt <path_to_hybrik_checkpoint.pth>
```

### Running the fitting (SMPLify-X)

```powershell
E:\envs\v23d_local\python.exe C:\V23D\V23D\third_party\smplify-x\smplifyx\main.py `
    --config C:\V23D\V23D\third_party\smplify-x\cfg_files\fit_smpl.yaml `
    --data_folder E:\zero123_dataset\humans_train\person_017\frame_000 `
    --output_folder E:\V23D_Data\smplifyx_output `
    --model_folder E:\SMPL_extracted\SMPL_python_v.1.1.0\smpl\models `
    --vposer_ckpt <path_to_vposer>
```

The fitted mesh is exported as `smpl_textured_from_splat.obj` — this is the mesh all later stages consume.

## 5. Stage 2 — Dual-View Texture Projection

**Script:** `project_face_body_dual_view.py`

### What it does

1. Loads the SMPL mesh (`smpl_textured_from_splat.obj`)
2. Loads front + back reference images
3. Detects body part regions in each image using YOLOv8 pose keypoints:
   - Face, hair, chest/torso, left arm, right arm, left leg, right leg
4. Projects SMPL mesh vertices onto each image plane
5. Samples pixel colors from detected regions per body part
6. Applies stretch-mapping for arms and chest (aligns mesh UV with image region)
7. Blends body texture and leg/pants texture at a division line (lower torso)
8. Runs **iterative kNN white-gap fill** (10 passes pre-shading, 4 passes post-shading)
9. Saves vertex-colored PLY and preview PNG

## 7. Stage 4 — Rebake Texture for Rigged FBX

The UV layout of `SMPL_m_unityDoubleBlends_lbs_10_scale5_207_v1.0.0.fbx` is **different** from the OBJ UV atlas.  
This step reprojects the baked texture into the FBX UV space so it displays correctly on the rigged model.

### Run command

```powershell
E:\envs\v23d_local\python.exe C:\V23D\rebake_texture_to_fbx_uv.py
```

Full CLI options:

```powershell
E:\envs\v23d_local\python.exe C:\V23D\rebake_texture_to_fbx_uv.py `
    --source_obj      E:\unity_vertex_match_output\our_pipeline_vertex_match.obj `
    --source_texture  E:\unity_vertex_match_output\our_pipeline_vertex_match_albedo.png `
    --target_fbx      "\\students\student-n-r\rgdix\Downloads\SMPL_m_unityDoubleBlends_lbs_10_scale5_207_v1.0.0.fbx" `
    --output_texture  E:\unity_vertex_match_output\SMPL_m_unityDoubleBlends_rebaked_albedo.png `
    --tex_size        4096
```

### Output

| File | Description |
|---|---|
| `E:\unity_vertex_match_output\SMPL_m_unityDoubleBlends_rebaked_albedo.png` | **← Use this in Unity** |

### How it works

1. Loads source OBJ UV layout + baked texture atlas
2. Loads target FBX UV layout (Open3D reads `triangle_uvs`)
3. For each triangle (both meshes share the same 13776-face SMPL topology):
   - Rasterizes target triangle in target UV space
   - For each pixel inside, interpolates source UV using barycentric weights
   - Bilinear-samples source texture at that source UV
4. Inpaints any unfilled UV seam gaps
5. Writes a new PNG ready for the FBX

## 9. Unity Import Instructions

### For the static OBJ (no rig)

1. Copy these three files into your Unity project `Assets/` folder together:
   - `our_pipeline_vertex_match.obj`
   - `our_pipeline_vertex_match.mtl`
   - `our_pipeline_vertex_match_albedo.png`
2. Unity auto-assigns the material. If it shows gray, open the material and drag the PNG onto **Base Map / Albedo**.

### For the rigged FBX (with bones + animations)

1. Import `SMPL_m_unityDoubleBlends_lbs_10_scale5_207_v1.0.0.fbx` into Unity `Assets/`.
2. Import `SMPL_m_unityDoubleBlends_rebaked_albedo.png` into the same folder.
3. In the Inspector, select the FBX → **Materials** tab → click **Extract Materials**.
4. Open the extracted material (used by the `m_avg` SkinnedMeshRenderer).
5. Set shader to **Standard** or **URP/Lit**.
6. Drag `SMPL_m_unityDoubleBlends_rebaked_albedo.png` onto the **Base Map / Albedo** slot.
7. The skinned mesh now has your texture and retains all joints (root, pelvis, spine, etc.) for animation.

## 10. Flags & Customisation

Edit these constants at the top of `project_face_body_dual_view.py`:

| Flag | Default | Effect |
|---|---|---|
| `APPLY_FACE_HAIR_TEXTURE` | `False` | Apply detected face/hair colors to face vertices |
| `APPLY_ARM_TEXTURE` | `True` | Apply stretch-mapped arm texture to arm vertices |
| `CHEST_DETECTOR_MODE` | `"yolo"` | Chest detector: `"yolo"` or `"mediapipe"` |
| `EXTERNAL_BACK_CHEST_RED_OVERLAY` | screenshot path | External chest mask image for the back view (optional) |
| `FRONT_REF_IMG` | frame_000 | Front reference image path |
| `BACK_REF_IMG` | frame_165 | Back reference image path |
| `OBJ_PATH` | `smpl_textured_from_splat.obj` | Input SMPL mesh |
| `OUT_PLY` | `smpl_textured_face_body_dualview.ply` | Output PLY path |
